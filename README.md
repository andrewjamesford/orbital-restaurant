# Orbital Restaurant

A demo Astro site for **Orbital** — a fictional space-themed restaurant located in Auckland's Wynyard Quarter.

## Tech Stack

- [Astro 5](https://astro.build/) - Static site generator
- [React 18](https://react.dev/) - UI components
- [Tailwind CSS](https://tailwindcss.com/) - Styling
- [Lucide React](https://lucide.dev/) - Icons

## Features

- Space-themed design with animated star backgrounds and orbital ring decorations
- Responsive navigation and hero section
- Interactive menu with categorised dishes (starters, mains, desserts, drinks)
- Mission/about section
- Contact form
- Custom UI components (buttons, cards, inputs)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/     # React components (Hero, Menu, Navigation, etc.)
│   └── ui/         # Reusable UI components (Button, Card, Input)
├── layouts/        # Astro layout templates
├── lib/            # Utility functions
├── pages/          # Astro pages
└── styles/         # Global CSS
```
